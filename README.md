# Integrality of design parameters and Fisher's inequality

Research notes from my student days, with a Lean 4 / Mathlib formalisation.

**Result.** Fisher's inequality `b >= v` for a non-trivial 2-`(v,k,lambda)` design is usually proved from the structure of the design. Is it already a consequence of the arithmetic relations `bk = vr`, `r(k-1) = lambda(v-1)` and integrality? For a fixed block size `k >= 2`: **yes if and only if `k` is a prime power.** For every other `k` there are integral parameter sets with `b < v` that only Fisher's inequality excludes (the smallest: `k = 6`, `(v, lambda, b, r) = (16, 1, 8, 3)`).

> **Status.** I did not find the prime-power criterion in a limited literature search, but I do not claim that it is new; the rest is standard (Fisher 1940, Bose 1949). Fisher's inequality has been formalised before (Isabelle: Edmonds-Paulson 2022; Lean 4: Wang-Uskuplu 2026); the Lean files here are independent of those and I have not compared them. The prose of the notes is not peer reviewed; the Lean files are machine-checked.
> The notes and the Lean files were prepared with the help of AI assistants (Claude, Anthropic); I directed the work and checked the results.

## Contents

- [`notes/notes.pdf`](notes/notes.pdf) (5 pages; source `notes/notes.tex`; build: `pdflatex notes.tex` twice): the theorem and its proof, the two classical proofs of Fisher's inequality (rank and variance), and a table of the parameter sets below the Fisher bound for `k <= 36`.
- [`notes/params.csv`](notes/params.csv): all 117 such parameter sets for `k <= 36`; generated by `notes/params_table.py`.
- [`lean/`](lean/): Lean 4 + Mathlib, no `sorry`, only the standard axioms (`propext`, `Classical.choice`, `Quot.sound`). Build: `cd lean && lake exe cache get && lake build`.

Main theorem in Lean (`lean/FisherNotes/Params.lean`): `fisher_of_integral_iff`.
